# Sanitized snapshot

This is a **sanitized, read-only snapshot** of the private repository that
runs my homelab fleet, published as the companion to the article
["Nine machines, zero USB sticks"](https://labodeludo.dev/en/blog/migrer-tout-mon-homelab-vers-nixos/)
(also available [in French](https://labodeludo.dev/blog/migrer-tout-mon-homelab-vers-nixos/)).

Hostnames, addresses (RFC 5737 / RFC 3849), SSH keys, certificates, disk
serials and MAC addresses are all fictional; every operational comment is
real. It is published to be read, not deployed — the flake will not build a
useful system for you as-is, and the repository is not maintained in sync
with the private original.
